# City & airport data sources

`app/src/main/assets/cities.db` is generated by `build_cities_db.py` from two open datasets.
Regenerate with `python build_cities_db.py --tier 500` (downloads sources on demand).

## GeoNames — cities
- URL: https://download.geonames.org/export/dump/ (`cities500.zip`, `countryInfo.txt`)
- License: **Creative Commons Attribution 4.0 (CC BY 4.0)** — https://creativecommons.org/licenses/by/4.0/
- Provides: city/town name, country, population, and the IANA time zone for ~211k places.

## OpenFlights — airports
- URL: https://github.com/jpatokal/openflights (`data/airports.dat`)
- License: **Open Database License (ODbL)** — https://opendatacommons.org/licenses/odbl/1.0/
- Provides: IATA code, airport/city name, country, and the IANA time zone for ~5.5k airports.

## Attribution requirement
Both licenses require attribution. Surface a credit such as:

> City data © GeoNames (CC BY 4.0). Airport data © OpenFlights contributors (ODbL).

in the app's About/Licenses screen when shipping.

## Schema (read directly, no Room metadata)
- `city(name, name_lower, ascii_lower, country, zone, population)`
  - `name` is the native/common display name ("Zürich"); `name_lower` is the diacritic-folded form
    ("zurich"); `ascii_lower` is the folded GeoNames romanization when it differs ("zuerich", or
    "tokyo" for native scripts) and "" otherwise. Search matches either folded column by prefix.
  - indexes on `name_lower COLLATE NOCASE` and `ascii_lower COLLATE NOCASE`
- `airport(iata, iata_lower, name, name_lower, city, country, zone)` + index on `iata_lower COLLATE NOCASE`
  - matched by IATA code (exact, then prefix) and by airport name as a substring ("heathrow").
- `schema_meta(version)` — bump `BUNDLE_VERSION` in the script (and `EXPECTED_VERSION` in
  `GeoPlaceRepository.kt`) when the bundled db changes, so the app re-extracts the asset.
